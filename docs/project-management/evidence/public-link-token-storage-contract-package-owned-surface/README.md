# Public Link Token Storage Contract Package-Owned Surface

This evidence package records the `public_link_token_storage_contract` package-owned read-model/report slice.

The slice moves the hash-only contract preview report assembly into `larena/link` and keeps the entry app as a compatibility wrapper. It does not create a persistent token table, database migration, production lookup, public file delivery, delivery adapter runtime, one-time consumption runtime, DB/file mutation or release-ready claim.
