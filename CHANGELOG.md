# Changelog

## Unreleased

- The `/larena/link/{token}` runtime-hardening preview route is removed with the report chain it composed (owner decision 2026-10-29: the storage-backed file-operation previews it started from are deleted): `PublicLinkRuntimeResolveController`, `PublicLinkRuntimeHardeningPreview`, `PublicLinkDryRunRuntimePreview`, `PublicLinkRuntimePlanningPreview`, `PublicContentLinkFlowPreview`, the `PublicLinkDryRunRuntimeReportSource` contract, the `public_routes.route`/`name` config keys and their tests. The route was local/testing only and answered a JSON preview report. Kept: the content link preview route, the token storage, persistent lookup, delivery readiness, delivery simulation, one-time consumption, real delivery adapter and link sharing reports, the link runtime and the lookup migration.
- Declaration hygiene (2026-10-29): the unused `require` of `larena/access`, `larena/audit`, `larena/core` and `larena/licensing` is dropped; the package names none of them in its code.
- The public link routes are the package's own (developer remark 5, 2026-10-26): Root's copy of `/larena/link/{token}` (`routes/larena/public.php`, `App\Http\Controllers\Larena\Public\PublicLinkRuntimeResolveController`) is removed, so `larena-link.public_routes.enabled` is now on by default and `LARENA_LINK_PUBLIC_ROUTES=false` turns it off (it used to be off unless set to true, with Root mounting its copy meanwhile). The provider still mounts the routes in local and testing only. The read-only JSON preview of a public content link moved here from Root too: `GET /larena/cms/content-links/{id}/preview` (`larena.cms-public-content-link.preview`, new `Http\Controllers\Public\CmsPublicContentLinkPreviewController`, config keys `public_routes.content_link_preview_route` and `.content_link_preview_name`); its answer names `larena/link` as the route owner (`route_provider_topology.current_owner`, `mounted_by`) instead of the Root placeholder fields. The config key `public_routes.entry_app_compatibility_route` is gone. `tests/Feature/PublicLinkPublicRouteRegistrationTest.php` runs in `composer test`.
- Removed the obsolete developer-preview screens under `/larena/internal` (owner decision 2026-10-26): the 17 review pages of the public-link tracks (content link flow, runtime planning, dry run, runtime hardening, token storage contract, persistent lookup, guarded delivery readiness, controlled delivery simulation, one-time consumption, guarded real delivery adapter, operator lifecycle, guarded admin mutation planning, revoke, regenerate, cleanup, mutation ladder, delivery contract hardening) and the `/larena/internal/public-link/assets/{assetKey}` stylesheet route, with their controllers, views, stylesheet, asset set (`assets.yaml`) and `PreviewResponder`; the report-source contracts only those pages read (all but `PublicLinkDryRunRuntimeReportSource`); the reports only those pages showed (cleanup, delivery contract hardening, guarded admin mutation planning, mutation ladder, operator lifecycle, regenerate and revoke previews); the planning and readiness objects `PublicLinkRouteProviderPromotionReadiness` and `PublicLinkRuntimePackagePublicScopePlan`; and the tests of those. The package no longer loads views or the internal route file.
- Kept: the public route `/larena/link/{token}` with its controller and every report it composes (runtime planning, content link flow, dry run, token storage, persistent lookup, delivery readiness, delivery simulation, one-time consumption, real delivery adapter, runtime hardening), `PublicLinkDryRunRuntimeReportSource`, the admin surface contributor, the link runtime, the content link read model and the lookup migration.
